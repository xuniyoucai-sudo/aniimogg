Aniimo 伊莫配置要求

《伊莫》官方 PC 最低和推荐配置，包括系统、CPU、显卡、内存、网络及硬盘空间。

发布日期2026-08-27更新时间2026-08-28资料版本Pre-launch信息状态官方已确认

撰写与审核 · Aniimo Guide Editorial Team · 最后审核 2026-08-28

最低配置

64 位 Windows 10；Intel Core i7-9700 或 AMD Ryzen 5 3600X；12 GB 内存；NVIDIA GTX 1060 或 AMD Radeon RX 6600；DirectX 11；宽带网络；45 GB 可用空间。

推荐配置

64 位 Windows 10 或更新版本；Intel Core i7-12700F 或 AMD Ryzen 7 7700X；16 GB 内存；NVIDIA RTX 3070 8 GB 或 AMD Radeon RX 6800；DirectX 11；宽带网络；45 GB 可用空间。

硬盘空间建议

商店标注为 45 GB 可用空间。实际安装时应额外保留解压、着色器缓存、更新补丁和截图所需空间。

笔记本与掌机

移动端显卡名称不能直接与桌面显卡等同。目前官方没有确认 Steam Deck 等掌机兼容性，不应在正式版测试前默认支持。

网络要求

Steam 明确要求宽带连接并包含在线互动。即使主要进行单人探索，也要为下载、账号服务和联网验证做好准备。
