处理的数据

Cloudflare 可能处理 IP 地址、请求信息、设备与浏览器信息、大致地区、页面访问及性能数据，用于传输和保护网站并生成聚合统计。

使用目的

相关数据用于内容分发、安全防护、防止滥用、故障排查、访问统计与 Core Web Vitals 监测。本站不会出售个人信息。

你的选择

你可以通过浏览器设置限制可选的浏览器存储。广告启用后，如站点提供同意管理入口，你也可以在那里重新调整选择。如有隐私问题，可通过联系与纠错页面反馈。

图鉴收藏与浏览器存储

图鉴使用浏览器 localStorage 保存你收藏的角色编号，不关联游戏账号，也不会跨设备同步。可点击收藏按钮取消单条收藏，或清除本站浏览器数据以删除已存收藏。禁止存储可能导致收藏无法保留。

搜索与外部链接

图鉴筛选在浏览器内运行。攻略搜索可能将关键词放入网址查询参数，因此可能出现在浏览历史和托管请求日志中。请勿在搜索框输入个人信息。打开官方来源或 GitHub 后，将适用对应服务的隐私政策。
