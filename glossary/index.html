Aniimo glossary

A multilingual reference for the terms used across our guides. Definitions distinguish official names from descriptive guide language.

Aniimo
Creatures players discover, catch and use in exploration and combat. Read guide →
Itepetl
A confirmed region of the Idyll world. Read guide →
Prismana
A form-related term used by the public index and rare-form guide. It must not be read as a capture region or a guaranteed stronger form. Historical regional wording is not a current coordinate source. Read guide →
Irisalis
A launch-version system or feature name referenced by the official developer letter. Read guide →
Capafruit
A launch-version training-related item or mechanic referenced by the official developer letter. Read guide →
Catching Twine
The capture tool described in official beginner materials. Read guide →
Evolution
A form-change system; exact release rules must be verified per Aniimo. Read guide →
Element
A combat affinity used for matchup descriptions. Read guide →
Role
A functional combat label such as offense or support. Read guide →
Egg Heist
A competitive mode with separately dated queue rules. Keep Chaos extraction rules, the Part 2 fair-PvP test and historical beta rules separate; see the mode guide. Read guide →
Chaos Mode
A launch-version mode confirmed by the developer letter. Read guide →
Crossplay
Cross-platform play and shared progression are different. Same-account, same-server progress is documented; check the current account-linking guide for platform-specific restrictions. Read guide →
Cross-save
Using shared progression across platforms; it is separate from crossplay. Read guide →
