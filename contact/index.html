Corrections and feedback

Use the GitHub issue tracker for corrections, source updates, accessibility problems, or site feedback.

What to include

Include the affected URL, game version or platform, what appears incorrect, and a reliable source or screenshot when available.

Privacy

Do not post passwords, account IDs, private messages, or other sensitive information in a public issue.
