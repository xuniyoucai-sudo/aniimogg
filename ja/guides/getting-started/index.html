Aniimo 初心者攻略

公式クライアントと正しいサーバーから始める

AniimoはPC・コンソール・モバイルで配信中です。Aniimo公式サイトまたは各公式ストアから入手してください。公式アカウント案内では、同一サーバー内の進行は機種間で共有され、異なるサーバーのデータは別管理です。長く遊ぶ前にサーバー名を確認します。

素材を使う前に導入を終える

チュートリアルで捕獲、Twine、戦闘、移動を学びます。字幕、操作、音声を先に確認し、序盤素材は正式版メニューで用途を理解してから使います。ベータ時のコスト、ルート、捕獲率は現在の手順ではありません。

メールとギフトコードを解放する

正式版の報告では Settings → Account → Gift Code Redemption からコードを入力します。報酬を受け取るゲーム内メールは、Chasing the Cloudsのストーリーを進めると解放されます。コードは大文字・小文字を区別し、期限や上限があります。

イベントの進行条件を目標にする

公式イベントの条件は、Windchaser’s DepartureがStudent I、Glamour StarとAniimo DiscoveryがStudent II、Holo-Battle InterlinkがTrailblazer I、Egg Heist Chaos ModeがTier IV Elite Egg Seekerです。ストーリーを飛ばす理由ではなく段階目標として使います。

公式の無料リリース報酬を受け取る

公式告知にはGrade I WayfarerでのレアPrismana選択、Aniilog収集アクセサリー、捕獲アイテム、累積ログインの限定タマゴ、無料衣装4着、事前登録報酬、機種横断ログイン報酬が掲載されています。実際の受取条件はライブ版で確認してください。

柔軟な初期チームを作る

役割、属性、現在の戦闘を理解する前に固定Tierをコピーしないでください。ダメージ、Break、耐久を意識しつつ、高価な強化は正式版のコストとルールを確認してから行います。

次の判断に合うページを使う

コードページでは証拠レベル付きのコード、イベントカレンダーでは期限、捕獲ガイドでは確認済みの流れを確認できます。機種やサーバーを変える前にはクロスプレイガイドを確認してください。

FAQ

Aniimoは現在プレイできますか？

はい。PC・コンソール版は2026年9月16日、iOS・Android版は9月23日に配信されました。

機種間で進行を共有できますか？

公式案内では同一サーバー内の進行を機種間で共有できます。異なるサーバーのデータは別管理です。

ギフトコード報酬を受け取るには？

Chasing the Cloudsを進めてゲーム内メールを解放し、Settings → Account → Gift Code Redemptionで入力後、メールから受け取ります。

現在のイベント解放ランクは？

公式1.1告知ではWindchaser’s DepartureがStudent I、Glamour StarとAniimo DiscoveryがStudent II、Holo-Battle InterlinkがTrailblazer I、Chaos ModeがTier IV Elite Egg Seekerです。

公式の無料報酬は？

レアPrismana選択、Aniilogアクセサリー、捕獲アイテム、累積ログインのタマゴ、衣装4着、事前登録報酬、機種横断ログイン報酬が告知されています。
