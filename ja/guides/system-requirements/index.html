Aniimoのシステム要件

Aniimo PC版のOS、CPU、GPU、メモリ、DirectX、通信環境、必要容量を公式情報から整理。

最低動作環境

64bit Windows 10、Intel Core i7-9700またはAMD Ryzen 5 3600X、メモリ12GB、NVIDIA GTX 1060またはAMD Radeon RX 6600、DirectX 11、ブロードバンド接続、空き容量45GBです。

推奨動作環境

64bit Windows 10以降、Intel Core i7-12700FまたはAMD Ryzen 7 7700X、メモリ16GB、NVIDIA RTX 3070 8GBまたはAMD Radeon RX 6800、DirectX 11、ブロードバンド接続、空き容量45GBです。

ストレージの余裕

ストア表記は45GBですが、展開用領域、シェーダーキャッシュ、アップデート、スクリーンショットのために追加の空き容量を確保してください。

ノートPC・携帯型PC

モバイルGPUは同名のデスクトップ版と性能が異なります。Steam Deckなどの正式対応は確認されていないため、発売後の実機検証を待つのが安全です。

インターネット接続

Steamではブロードバンド接続が必須で、オンライン要素も明記されています。ソロ中心でもダウンロードやアカウントサービスへの接続を想定してください。

FAQ

Aniimoに必要な空き容量は？

Steamでは最低・推奨ともに空き容量45GBと記載されています。

AniimoにSSDは必須ですか？

Steamの要件表ではSSD・HDDを指定していません。展開とアップデート用の余裕は確保しつつ、ドライブ種別を必須条件とは扱わないでください。

ノートPCで遊べますか？

搭載CPU・GPUをデスクトップ向け要件と比較してください。モバイルGPU名は同名のデスクトップGPUと同等ではありません。

AniimoはSteam Deck対応ですか？

公式確認はまだありません。現在の根拠はSteam Deck対応状況ページで確認してください。
