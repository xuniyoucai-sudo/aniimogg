推奨動作環境

64bit Windows 10以降、i7-12700FまたはRyzen 7 7700X、メモリ16GB、RTX 3070 8GBまたはRX 6800、空き45GBです。

DLSS 4.5を公式発表

DLSS 4.5 Dynamic Multi Frame Generationと第2世代Transformer Super Resolutionの導入が発表されています。

容量・ノート・携帯型PC

45GBに加えて展開、キャッシュ、パッチ用容量を確保。モバイルGPUはデスクトップ版と同等ではなく、Steam Deckも未確認です。
