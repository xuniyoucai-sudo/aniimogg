# Aniimo public-build validation checklist

Use this internal checklist from the PC and console public release on 2026-09-16. It is not a player-facing guide and must not be treated as evidence until a tester records a platform, version, date, route, and result.

## Recording rule

- Record platform, storefront, region, game build/version, local time, tester, and an unedited screenshot or short capture where appropriate.
- Mark every item as `confirmed`, `changed`, `not available`, or `needs retest`.
- Update a public guide only when the result is repeatable. Mark the public claim `Release-tested` and retain the prior Beta wording in its change log when it materially differs.
- Never infer console, mobile, cross-platform, or account behavior from one PC observation.

## Account, download, and launch

- [ ] Official store availability, exact unlock time, download size, and day-one patch size: Steam, Epic, PS5, Xbox.
- [ ] Login/account creation flow and whether the same email offers an account-linking prompt.
- [ ] Server list, region names, maintenance notices, queue behavior, and character-creation restrictions.
- [ ] Free base-game availability versus paid pack contents, regional pricing, and store description changes.

## Controls and Aniimo management

- [ ] Menu path to Aniimo Management on PC; record the final default key and whether Esc is still correct.
- [ ] Active combat Aniimo selection and swap behavior: input, combat restriction, cooldown, and tutorial wording.
- [ ] Roster switching: final H key or equivalent, roster count, team slots, presets, unlock conditions, and whether switching is allowed in co-op.
- [ ] Twine input, selection rules, transformation limits, and controller mapping.
- [ ] Remapping, hold/toggle, sensitivity, vibration, adaptive triggers, subtitles, practice mode, manual saves, and voice-chat transcription by platform.

## Multiplayer and progression

- [ ] Crossplay pairings, party-size limits, invite/friend flow, server restrictions, and PvP/Egg Heist availability.
- [ ] Cross-save, cross-progression, account linking, shared purchases, and character-transfer behavior; test each only with official permission and separate accounts where required.
- [ ] Solo/co-op story boundaries, guest quest credit, catches, rewards, and host-world progression.

## Gameplay data

- [ ] Catching and Twine tutorial flow, tools, timing, failure states, environmental conditions, and any changed Beta terms.
- [ ] Elements, roles, forms, evolution conditions, team-building costs, currencies, resources, and tutorial explanations.
- [ ] Region labels, map boundaries, coordinates, fast travel, resource nodes, weather, quests, and creature spawns. A map entry needs a reproducible route and conditions.
- [ ] Steam Deck and cloud-gaming behavior only after a real device/session check; do not convert store compatibility guesses into claims.

## Publishing and SEO follow-up

- [ ] Change each affected guide's information status, game version, last-updated date, change log, FAQ, source list, and related links.
- [ ] Keep English, `/zh-cn/`, and `/ja/` aligned; verify self-canonical, `hreflang`, HTML `lang`, Article/FAQ schema, image alt text, and sitemap entries.
- [ ] Run build, multilingual checks, and a mobile viewport review before publishing; submit changed URLs through the normal sitemap/IndexNow workflow only after deployment.
