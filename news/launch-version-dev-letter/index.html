Aniimo Dev Letter Confirms Launch-Version Changes

Xbox cloud gaming, Egg Heist Chaos Mode, revised catching, training, Home and control improvements are confirmed for launch.

Pawprint Studio confirms that Aniimo launches September 16 on PC, consoles and Xbox cloud gaming, with mobile following September 23. Xbox cloud gaming is the only cloud service named; GeForce NOW and other catalogues remain unconfirmed.

Official launch updates

The launch version redesigns the Irisalis encounter and Prismana acquisition, removes the carried-item rune system, simplifies training, expands Home features, improves mobile and controller input, adds main-story multilingual voiceover, and upgrades Egg Heist with more egg types and a high-difficulty Chaos Mode.
