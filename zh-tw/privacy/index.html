隐私政策

本站目前沒有账號、留言、電子報或已啟用的廣告服務。Cloudflare 為本站提供托管、安全、聚合流量統計與真實用户性能监測。

处理的數据

Cloudflare 可能处理 IP 地址、請求信息、設备與浏覽器信息、大致地區、頁面訪問及性能數据，用於傳輸和保護網站並生成聚合統計。

使用目的

相關數据用於內容分發、安全防護、防止滥用、故障排查、訪問統計與 Core Web Vitals 监測。本站不會出售個人信息。

廣告状態與第三方服務

本站目前未啟用 Google AdSense 或其他廣告服務。如未來啟用廣告，Google 及其廣告合作方可能使用 Cookie 或類似技術進行廣告投放、反欺诈、效果衡量，以及在法律允許時提供或衡量個性化廣告。廣告上線前會更新本政策。

Cookie 與同意

若未來啟用廣告，位於需要同意機制地區的訪客會在使用非必要廣告技術前看到相應的同意選項。訪客可接受、拒絕或管理同意；非必要廣告 Cookie 不會被視為網站正常运行所必需。

你的選擇

你可以通过浏覽器設置限制可選的浏覽器存儲。廣告啟用後，如站點提供同意管理入口，你也可以在那裡重新調整選擇。如有隐私問題，可通过聯系與纠错頁面反馈。
