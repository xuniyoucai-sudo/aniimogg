最後审核 · 2026-09-11

已於 2026 年 9 月 11 日重新核查官方來源；尚無新增的平臺專屬細節，以下未確認事項繼續明確標注。

最低配置

64 位 Windows 10；Intel Core i7-4770 或 AMD Ryzen 7 2700；8 GB 內存；NVIDIA GTX 970 或 AMD Radeon RX 5600；DirectX 11；宽帶網絡；40 GB 可用空間。

推荐配置

64 位 Windows 10 或更新版本；Intel Core i7-10700 或 AMD Ryzen 5 5600 或更高；16 GB 內存；NVIDIA RTX 3060 或 AMD Radeon RX 6700；DirectX 11；宽帶網絡；40 GB 可用空間。

Intel 第 13／14 代穩定性公告

Pawprint Studio 表示，部分使用受影响 Intel 第 13／14 代 Core 臺式機处理器的電腦，若微代碼过舊，可能發生崩溃、卡死、圖形异常、顯存不足報错或藍屏。這是处理器穩定性提示，並不代表每臺 Intel 電腦都會受影响。

出現症状時怎麼辦

官方建議遵循 Intel 或主板廠商的 BIOS 指引，升級到最新 BIOS 並使用 0x12B 或更新的 Intel 微代碼。公告也鏈接 Intel XTU，並說明可下調性能核心倍頻 2–3 檔；固件或調校設置有風险，不熟悉時應寻求硬件廠商支持。

DLSS 4.5 已確認

官方宣布集成 DLSS 4.5 Dynamic Multi Frame Generation 與第二代 Transformer Super Resolution。

仍未確認的圖形功能

最終顯卡支持表、預設、延迟與分辨率性能尚未公布；FSR、XeSS、光追和帧率上限也未獲官方確認。

存儲、笔記本與掌機

除 40 GB 外應預留解壓、緩存與補丁空間；移動顯卡不能直接等同桌面型號，Steam Deck 仍未確認。

網絡要求

Steam 要求宽帶網絡並列出在線互動。
