Aniimo Controller Support and Accessibility

Compare Aniimo’s official PC controller list with the current PS5 accessibility listing, platform limits and a practical input-check workflow.

Published2026-09-01Updated2026-10-18Information versionUS PlayStation three-feature listing checked October 18 / official September 14 PC controller chartInformation statusOfficial information

Written and reviewed by · Aniimo Guide Editorial Team · Last reviewed 2026-10-18

Current PS5 listing: three features

The US PlayStation page checked October 18 lists Subtitles (Basic), Game Speed (Basic) and Control Reminders. Basic subtitles cover the main story and main characters; basic game speed permits slowing only for limited time or specific actions.

Correcting the previous feature list

Aniimo.GG previously listed 15 PS5 features. That claim is withdrawn against the current storefront. Remapping, stick sensitivity, manual saving, voice transcription and disabling vibration or adaptive triggers are not confirmed by its present accessibility section. The PS5 version label currently says vibration and trigger effect are required; verify specific needs in the live game before relying on a setting.

PC controller models in the official chart

PS4 / PS5 / DualSense Edge (PS5) / Xbox / Xbox Elite / Xbox 360 / Nintendo Switch Pro Controller / Nintendo Switch 2 Pro Controller / 8BitDo Pro 2 / Betop Asura / Machenike G5 Pro. This is the PC row of the official chart dated September 14, not a console or mobile compatibility promise.

Hardware support and accessibility answer different questions

A listed controller model does not establish every connection mode, button remap or assistive-device workflow. For mobile, use the dedicated requirements guide; its controller restrictions differ from PC.

Verify contextual controls before changing settings

The two community controls guides disagree on some action labels and rebinding scope. Use their versioned examples as leads, then check the current device glyphs, active mode and binding screen. An action may change with the controlled Aniimo or target.

A practical input check

Aniimo.GG recommends testing one supported device in a tutorial, checking menu navigation and one contextual action, then changing one setting at a time. Record platform, client version, controller model, connection method and the failed prompt when contacting support.

FAQ

Which PS5 accessibility features are currently listed?

Basic subtitles, basic game speed and control reminders. The earlier 15-feature claim has been corrected.

Can vibration and adaptive triggers definitely be disabled?

The current PS5 version label says vibration and trigger effect are required. This guide cannot confirm disabling options without a live check.

Does a supported PC controller also work on mobile?

Not automatically. The official chart has separate PC and mobile rows; see the mobile guide for restrictions.

Are old Beta PC keys current defaults?

The Beta handbook is historical. Check current prompts and bindings before using a shortcut.

Can every keyboard or controller action be remapped?

The compared community guides disagree about scope. Check the current platform’s binding screen; this page does not promise full remapping.
