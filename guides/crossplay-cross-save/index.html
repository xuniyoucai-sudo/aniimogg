Aniimo Crossplay, Account Linking and Shared Progress

Official Aniimo cross-progression and account-linking rules, console first-login prompts, PSN server matching, reward claims and support checkpoints.

Last reviewed · 2026-09-16

Official sources rechecked September 16, 2026. The newly published PC and console FAQ is reflected below; details the FAQ does not address remain explicitly marked.

Same server is essential

The official FAQ confirms progress sharing across platforms within the same server. Different servers keep separate data. Crossplay, account identity and reward claims need separate checks.

PS5 and Xbox first login

The September 14 FAQ says an eligible PSN or Microsoft profile receives its existing Aniimo Pass linking prompt only on first login. Skipping it creates another Pass and prevents that profile from linking to an existing Pass through that route. Read the current prompt before continuing.

PSN region and server matching

PlayStation assigns the Aniimo server from the PSN account’s registered region. Compare it with your existing character before linking; cross-server progress sharing is not supported. The official FAQ includes a country/region table.

Steam and mobile email linking

The mobile FAQ documents Steam linking through the client prompt or later Email Link page. It also describes a third-party first-login Link Email prompt and limits each platform account to one linked email, while one email can have multiple platform accounts.

Test rewards need their own check

The September 15 reward notice recommends using the test email through direct email login rather than assuming third-party Google sign-in is identical. If you already have a character you need to preserve, or received Steam test rewards, the notice directs you to Customer Support. It also warns that a skipped website/mobile first-login link may require support.

What the official purchase example actually covers

Console pre-order packs must be claimed on the purchase platform. The FAQ says claimed accessories and items can then be used across linked platforms on the same server. This specific example does not establish universal currency-wallet sharing or refund rules.

Before adding another platform

Aniimo.GG recommends recording character name, server and current login method first. Confirm the destination platform profile and email, complete the correct prompt, then verify the same character before claiming rewards. If a new-character screen appears unexpectedly, pause and contact official support rather than unlinking accounts by trial and error.

Official FAQ confirmation

The official September 14 PC and console FAQ says that game progress is fully shared across all platforms within the same server, while data on different servers is independent. This is an explicit progress-sharing statement, not an inference from a store feature label.

FAQ

Is Aniimo crossplay?

Steam lists cross-platform multiplayer. The official FAQ separately confirms same-server progress sharing.

Can I transfer a character to another server?

The official FAQ says servers have independent data and PS5 has no cross-server progress sharing.

Can I skip console linking and link an existing Pass later?

The console FAQ says the first-login popup is the only opportunity for that route. If skipped or mismatched, ask official support about your case.

Why can I not see my PC character on PS5?

Compare account identity and PSN-assigned server with the PC character. Preserve the current character and contact support if the match is unclear.

Can I claim a console pre-order pack on another platform?

The official FAQ requires claiming on the purchase console; claimed accessories and items can be used on linked platforms within the same server.

Does Google sign-in equal entering the same email?

Do not assume so. The test-reward notice recommends direct email login for the test account and directs existing-character cases to support.
